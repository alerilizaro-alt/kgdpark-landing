# Files Directory

This directory contains downloadable files for the KGD Park website.

## Required Files

### presentation.pdf
- **Location:** `/files/presentation.pdf`
- **Public URL:** `https://www.kgdpark.com/files/presentation.pdf`
- **Purpose:** Investment project presentation document that opens automatically after user registration
- **Behavior:** After user submits the registration form (name, email, and privacy consent), the PDF automatically opens in a new browser tab
- **Action Required:** Please upload your presentation PDF file to this directory with the exact filename: `presentation.pdf`

### MasterPlan.pdf (Legacy)
- **Location:** `/files/MasterPlan.pdf`
- **Note:** This is an alternative filename. The system now uses `presentation.pdf` for consistency.

## Notes
- The contact form popup on the website links to `presentation.pdf`
- Users must register (name, email) and agree to privacy policy to access the download
- The PDF opens automatically in a new tab 800ms after successful form submission
- A fallback button is provided if the automatic opening is blocked by the browser
- Make sure the PDF file is optimized for web viewing
- Recommended file size: under 10MB for faster downloads
- The same behavior applies to both Russian and English versions of the site
